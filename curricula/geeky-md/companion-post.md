# Python Basics for a Geeky Doctor — What I'm Learning This Month

As a healthcare professional, I'm diving into Python to automate the repetitive data tasks that eat up my time. This curriculum teaches me to write scripts that organize patient information, process medical records, and filter datasets—all without prior coding experience. Each 20-30 minute phase builds practical skills through a medical lens, from storing vital signs in variables to reading CSV exports from our hospital system. By the end, I'll be able to build a complete data pipeline that reads, processes, and reports on patient data automatically.

**Highlights**

- **What's included:** 5 progressive phases covering Python fundamentals, data structures, control flow, file handling, and building complete workflows—all with healthcare examples
- **Who it's for:** Doctors, nurses, researchers, and healthcare professionals with zero programming experience who want to automate medical data tasks
- **How to use it:** Work with an AI teacher (ChatGPT, Claude, etc.) using copy-paste prompts, complete planning activities (no coding required), and build toward a capstone project like a patient reminder system or medication inventory tracker
- **Time commitment:** 2-3 hours total (five 25-minute phases), perfect for busy medical professionals learning in short sessions

**Why this matters:** Healthcare generates massive amounts of data, but most of us weren't trained to process it efficiently. Learning Python basics opens the door to automation, better patient care through data insights, and a foundation for health informatics and AI applications in medicine.
