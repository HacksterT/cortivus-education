# Python Basics for a Geeky Doctor — Companion Checklist

_Quick prompts to keep you moving. Pair with the **Core Curriculum**._

**How to use:** For each phase, ask 1–2 prompts, do the activity (describe/plan, no code), then capture a 3‑bullet reflection.

---

## Phase 1 — Python Fundamentals: Your First Medical Script

- **Ask:** "Explain Python variables using a medical example like storing patient temperature"
- **Ask:** "Walk me through writing my first Python script that prints a clinic welcome message"
- **Activity:** Describe a script that stores and displays patient info (name, age, BP, temp)
- **Reflect:** What medical task could benefit from automated information display?

## Phase 2 — Data Structures for Healthcare Information

- **Ask:** "How do I use a dictionary to represent a patient's complete medical record?"
- **Ask:** "What's the best way to store multiple patients with multiple attributes each?"
- **Activity:** Design a data structure for 3 patients with name, age, diagnosis, medications list, last visit
- **Reflect:** How do lists/dictionaries improve patient information management vs. paper?

## Phase 3 — Control Flow: Making Decisions with Patient Data

- **Ask:** "How do I write an if statement to flag patients with fever (temp > 100.4°F)?"
- **Ask:** "Explain using a for loop to process 10 patients and filter by high blood pressure"
- **Activity:** Describe triage system logic that categorizes patients as urgent/moderate/routine based on vitals
- **Reflect:** What repetitive medical decision could be automated with conditional logic?

## Phase 4 — File Handling: Working with Medical Records

- **Ask:** "How do I read a CSV of patient data and convert it to a list of dictionaries?"
- **Ask:** "What's the safe way to write processed data to a new CSV without losing the original?"
- **Activity:** Plan a script that reads lab results CSV, identifies abnormal results, writes to flagged_results.csv
- **Reflect:** How would CSV processing save time vs. manual review of medical data?

## Phase 5 — Putting It Together: A Mini Medical Data Pipeline

- **Ask:** "How do I organize a script that reads, filters, and generates a patient summary report?"
- **Ask:** "What's the best way to test with sample data before processing real patient files?"
- **Activity:** Design "Daily Patient Summary" workflow: read CSV → categorize by department → count visits → flag abnormal vitals → write report
- **Reflect:** What medical data task could you now automate? What skills will you use?

---

## Capstone Project

Choose one option:

- **Option 1:** Patient appointment reminder system (read appointments CSV, identify who needs reminders)
- **Option 2:** Medication inventory tracker (process med list, track quantities, flag low stock)
- **Option 3:** Symptom checker processor (categorize symptoms by severity/system)

**Deliver:**

- 1-page write-up: problem, data structure, logic flow, expected output
- Resources list: what structures/control flow/file ops you'll use and why
- 3 lessons learned: technical insight, practical application, area to explore further
